# ASM-8086-SIM — Audit 2026-09-14

**Scope:** whole project (13,024 LOC / 179 files) · **Method:** read + executed engine probes · **Baseline:** `d3e6ed9`

**Verdict at start:** healthy. Every gate the repo defines passed from a clean
checkout — 533 tests / 18 files, 0 lint warnings, 0 type errors across all
three tsconfigs, clean build, 0 npm advisories, 89% statement coverage in

engine, not by reading it.

## Found while fixing

- **`pages-smoke.spec.tsx` could never satisfy its own waits.** Two 4 s
  `waitFor` budgets inside vitest's 5 s default `testTimeout`. It passed only
  because it normally finished in ~2.3 s; under full-suite parallel load it
  timed out intermittently. Given an explicit 20 s timeout.
- **Stored theme was cast, not validated.** `localStorage.getItem(THEME_KEY) as AppTheme`
  applied any string as a `data-theme` attribute. Now checked against the
  known set.

## Not done, deliberately

- **String instructions** (`MOVSB`/`STOSB`/`LODSB`/`CMPSB`/`SCASB`/`REP`) and
  `STI`/`CLI`. These are the largest remaining instruction-set gap and would
  make DF load-bearing, but they are a feature, not a defect fix — roadmap
  MOVE-2.
- **Major dependency upgrades.** vitest 4→5, jsdom 26→30, TypeScript 6→7.
  Each deserves its own PR and its own read of the changelog, which is
  precisely what the new Dependabot config will produce.
- **Rewriting git history** to purge `extracted/`. Untracking stops further
  publication; for a personal study repo with no secrets involved, a rewrite
  costs more than it returns.
